# 小家键盘 · 安卓源码

基于Xime/Rime的独立中文输入法，修改版按GPL-3.0分发，保留原作者版权与第三方许可。不是Xime官方版本。此目录对应20261069源码，开发中的功能和真实设备兼容性仍需验收。

## 简单使用

在系统设置中启用并切换小家键盘。装扮页点击预览选键，保存并应用。剪贴板里可写草稿、选取一小段放进输入框。连接自己的HTTPS服务器，领取绑定码；了解隐私风险后自行开启自动同步。日常使用流量请关闭“只在Wi-Fi下发送”。不上传逐个按键，过滤不能保证识别所有敏感资料。

输入英文半角 `@` 后可在候选栏选择邮箱后缀；App首页「邮箱后缀」可编辑1到12个域名、排序或关闭。此功能仅本地补全，不保存正在输入的邮箱，不在密码框或有未完成拼音、选区时显示；不提供光标上下文的输入框可能无法显示。

装扮页→我的预设→「复制DIY码」可离线分享完整数值和实际引用的贴纸/壁纸；朋友升级69版后点「输入DIY码」粘贴或输入，先预览再保存。XJ1格式无损压缩，图片多会更长，复制码最多2万字，并主动保存到键盘本地剪贴板；更长的请「导出TXT」作为附件，朋友点「导入TXT」。65版已复制的较长码仍可导入；原有装扮文件也兼容，不会省略素材。TXT文件名默认跟随预设名。不包含账号、剪贴板、草稿、语音及输入方案等独立设置。分享自己的或有权分享的图片。

67版装扮：正方形键帽可调圆角、26键与九宫格主键区逐行调间距；上方栏独立壁纸/四边阴影，快捷图标可换图片、手势摆放和排序；大字/小字不透明度可分别调，编辑器保留文字操作虚线边框，变色选项、图标和预览不额外套框。新参数和素材一起进入DIY码/TXT，接收方请更新69版。

68版：单项同步用双箭头与长按说明，整套操作保留短标签；同一颗按键最多叠8张贴纸，每张独立选覆盖键内/自由、图片、位置、大小、旋转、透明度及阴影上下层。点数字切换编辑目标，＋添加，上下箭头调整同层顺序；手势微调只改选中一张。整张、单项、全部贴纸同步范围分开，完整图片随DIY/TXT带走。旧单张设置保留，新装扮接收方请更新69版。

69版：整体行缝最小0dp，调整整体会清掉旧逐行覆盖，使所有行跟随；整体与逐行滑条在0附近更细，可点数值精确输入。点预览选键→按键→这颗键的大小：主键区宽度0.5—2倍，会重排行内键位；高度为原行内40%—100%，九宫格侧栏宽度最多填满原槽位。手势微调→按键大小支持双指捏合；可分别同步宽、高或整套尺寸，随DIY/TXT保存。旧装扮默认尺寸保持1。

## 构建

需要JDK21、Android SDK/NDK/CMake（版本见Gradle文件）、Python3、Git、Node，以及构建插件所需的Rust/Cargo。下载依赖需要网络。

1. 在本目录运行 `python fetch-sources.py`，取得SOURCE_DEPENDENCIES.json固定到实际使用提交的7个源码仓库；递归子模块由上游提交锁定。
2. 配置本机SDK路径local.properties，安装Gradle声明的NDK/CMake。
3. 按scripts/build-plugins.sh构建并同步内置插件；详见tools/xime-plugin/README.md。
4. Windows运行 `gradlew.bat assembleDebug -Pandroid.injected.build.abi=arm64-v8a -Pandroid.injected.testOnly=false`；其他系统运行 `bash gradlew assembleDebug` 并选择所需ABI。

Gradle/CMake会下载指定版本的Boost、ONNX、knf等依赖，版本/来源/校验保留在构建脚本中。使用自己的签名密钥；不会公开原发行私钥。

本目录来自69版通过137项外观与按键路由定向JUnit、arm64构建及Android界面测试源码编译的开发工作树；界面用例未执行，实际触屏/视觉仍待手动验收。本阶段未重跑服务器TLS契约（67版已通过）；导出后校验文件哈希/隐私与源码锁，尚未在第二台空白机器全量重建。普通构建无需原作者的小家服务器；本机TLS测试另需隔离夹具。
