# Open Source Projects

This repository is a collection of independent open-source projects. Each project lives in its own directory and contains its own README, dependency definition, license, and deployment guidance.

## Projects

- [`little-home-keyboard-server`](./little-home-keyboard-server/) — 小家键盘的独立剪贴板接收器与网页装扮工作台，GPL-3.0；使用自己的服务器和凭证。

- [`reading-room-mcp`](./reading-room-mcp/) — a small FastAPI reading application with MCP tools for book progress and notes.

Runtime data, credentials, uploaded content, logs, backups, and environment-specific configuration must not be committed.
