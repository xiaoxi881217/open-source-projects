装扮工作台

这一颗 · Q

folio 01

先点选一颗键，再选移动文字或摆放贴纸。贴纸可双指缩放、旋转。

整体配色与预设

单指移动、双指缩放；壁纸随完整装扮导出，只存本机。网页请选择PNG，安卓也支持JPEG/WebP。

整体圆角会统一全部按键，替换各键原来的圆角，可撤销；之后仍可独立调整。

这颗键的颜色与圆角

底色越透明，越能看见壁纸与磨砂；字母和贴纸保持清晰。

0为透明，1为实色；主文字、贴纸与阴影分别设置。

上方小数字 · 符号点开调整

选“移动文字”后可双指捏合调字号，与候选词字号分开。

文字精确位置
这一颗的贴纸

贴纸越过别的键时，点击仍由下面的真实按键接住。

在上方“在预览里做什么”选择摆放贴纸，直接拖动、捏合和旋转。

贴纸精确数值

数值同步只调整已经有贴纸的目标键。整张贴纸和图片同步可以给目标键加上贴纸。

四边独立阴影

四边光影独立设置，模糊会自然交叠。

震动与按键音

网页反馈只供本机试用，不打包进主题。安卓装扮页可进入原有震动与按键音设置，支持系统跟随、强度、长按和抬起反馈。

按下去的质感

可选开启，关闭后不遮住键帽动态；安卓长按菜单与滑动提示照常。

动态只改变画面，触摸区域留在原位；尊重系统减少动态效果。

装扮草稿自动保存在这台浏览器，刷新后可以继续。导出并在安卓中导入，才会应用到手机（壁纸、磨砂和文字设置需要新版 APK）；这里不读取或上传剪贴板。快捷图标为网页示例，安卓使用手机的实际配置。

主题参数与支持内阴影的新版安卓共用 JSON 格式；网页的光影与动画会有渲染差异，最终仍需手机验收。贴纸可以叠在配色与阴影上；网页预览支持 PNG，安卓还可导入 JPEG/WebP。连接面板请在安卓中使用。
