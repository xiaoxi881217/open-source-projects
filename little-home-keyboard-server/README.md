# 小家键盘 · 自己的小剪贴板

这是配套服务器接收器与网页装扮工作台。可以部署到自己的HTTPS域名，让自己授权的手机上传复制片段，再接入自己的AI工具。

- 手机系统输入法需单独安装APK；本目录不包含安卓APK或安卓对应源码。
- 首次部署：生成自己的管理凭证与可选只读工具凭证，按下方说明启动服务；不能直接照抄示例凭证。
- 手机连接：填HTTPS根地址，领取一次性绑定码，绑定后自行同意开启自动同步。仅Wi-Fi开关关闭时可以使用流量。
- 默认不上传输入的每个按键；敏感过滤有误判/漏判风险。这里只保存实际上传的剪贴板资料。
- 许可证见LICENSE和THIRD_PARTY.md。无需接入原作者的小家服务器。

# 小家键盘 · 干净服务器部署包

含独立小剪贴板接收器和可编辑的网页工作台源码。安卓系统键盘仍是手机App，服务器网页不是系统输入法。包内没有私人预设、剪贴板、草稿、数据库、地址、账号、设备令牌或签名私钥。草稿始终保存在手机本机，不上传到本接收器。

## 用自己的服务器部署

1. 安装Docker和Compose，将包解压到独立目录。
2. 复制 `.env.example` 为 `.env`，把INBOX_DOMAIN改为自己的域名，并将DNS指向此服务器；开放80/443。管理凭证用 `python -c "import secrets; print(secrets.token_urlsafe(32))"` 现场生成，填入INBOX_OWNER_TOKEN。不要使用示例固定凭证。ALAN/YAN读取凭证可留空关闭；要启用则分别生成，不能相同或复用管理凭证。
3. `chmod 600 .env`，然后 `docker compose up -d --build`。接收器没有公开HTTP端口，只通过Caddy提供HTTPS；Caddy自动申请正规证书。若已有反代，按Caddyfile路径规则接到接收器，保留HTTPS和正确Host/代理配置。
4. 访问 `https://你的域名/` 打开外观工作台；访问 `/api/our-home/clipboard/manage` 管理小剪贴板，填写自己生成的管理凭证，再生成五分钟绑定码。
5. 手机打开小家键盘→我们的小家，填写 `https://你的域名` 并绑定设备。自动同步默认为关闭，首次需本人确认；连接失败不影响离线输入。
6. AI接入见《AI工具接入.md》。独立桥不会自动连接或修改任何人的人格服务。

## 验证与边界

`pip install -r requirements-test.txt` 后运行 `python -m unittest test_standalone.py`。本地测试覆盖鉴权、双设备隔离、绑定上传与双身份去重，不产生真实生活数据。Docker/Caddy公开DNS与证书签发需在目标服务器验证，本机构建不等于公网验收。

数据卷inbox-data保存私有数据库；备份前先停止接收器或用SQLite在线备份。不要把 `.env` 或数据库放进网页目录。代理访问日志应保持关闭或避免记录请求内容/Authorization；请勿放宽证书验证。重装清空数据卷会丢失绑定和片段。

网页装扮只在浏览器本机保存，导出完整装扮再到安卓“我的预设→导入”，不会把个人主题自动发给服务器。包中web/LICENSE为所复用Xime网页音频/衍生部分的GPL许可，全部网页源码随包提供；第三方依赖各自许可证仍适用。接收器来自本项目自有独立模块，保留了原接口与校验，没有复制私人上下文、人格提示词或密钥。
